# 00 索引与阅读指南

> 基于 diffusers 0.39.0.dev0 版本

## 1. 项目背景简介

HuggingFace Diffusers 是 HuggingFace 团队维护的扩散模型（Diffusion Models）推理与训练库，致力于为扩散模型的加载、调度、采样和部署提供统一、易用且高性能的 API。本代码分析文档集基于 diffusers 0.39.0.dev0 版本撰写，覆盖从底层基座到顶层管道的完整推理链路。

Diffusers 的核心由三大组件构成：

- **diffusion pipelines**：高层管道，封装"模型 + 调度器 + 引导器 + 处理器"的端到端推理流程，对用户暴露统一的 `__call__` 接口。
- **schedulers**：调度器，定义扩散过程的前向加噪与反向去噪规则（DDPM、DDIM、Euler、DPM-Solver 等），决定采样质量与速度。
- **models**：模型层，承载 UNet / Transformer / VAE / ControlNet 等网络结构，是噪声预测与图像重建的执行主体。

本套文档采用"总—分—总"风格组织：以总览开篇勾勒架构，分篇深入各模块实现，最终以推理全链路总结收尾，共 18 篇（含本索引与待生成的附录）。本篇作为索引入口，提供目录导航、推荐阅读路径与阅读约定，帮助读者快速定位感兴趣的主题。

## 4. 阅读约定

- **文件链接**：所有跨文档引用均使用 `[文件名](file:///workspace/ReadCode/文件名.md)` 格式，可在支持本地文件跳转的 Markdown 查看器中点击直达。
- **Mermaid 图表**：全文采用 ```mermaid 代码块标注，需在支持 Mermaid 渲染的环境中查看，如 GitHub 在线渲染、VSCode 安装 "Markdown Preview Mermaid Support" 插件、Typora 等。
- **代码示例**：基于 diffusers 0.39.0.dev0，运行示例需先安装 `pip install diffusers[torch] transformers accelerate`；涉及 GPU 加速的案例需要 CUDA 环境。
- **命名约定**：类名、方法名、字段名保留英文原文（如 `DiffusionPipeline`、`from_pretrained`、`config.json`），便于与源码对照；正文说明使用中文。
- **图编号**：每张图以"图 X-Y"编号，X 为所在文档编号，Y 为该文档内序号；图前有加粗标题，图后紧跟"说明"段落。
